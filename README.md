Hi, we're Exa/exaptations. We've been modding Minecraft for ~14 years. It's horrifying. When not doing that, we run various services and develop assorted (mostly game-adjacent) software.

Check out our [personal website](https://exa.y2k.diy) for more.

**We use our own self-hosted [Forgejo](https://git.sleeping.town/exa) these days.**

Assorted notable projects:
* **[AsyncSimpleLog](https://git.sleeping.town/exa/AsyncSimpleLog)** - A fast, small, and useful logger implementation for SLF4j. 
* **[FlexVer](https://git.sleeping.town/exa/FlexVer)** - A SemVer-compatible intuitive comparator for free-form versioning strings as seen in the wild, designed to sort versions like people do. 
* **[SymbolicControllerDB](https://git.sleeping.town/exa/SymbolicControllerDB)** - The SDL controller DB is how controllers behave. What if we had a database of how they look? 
* **[Jortage](https://git.sleeping.town/jortage)** - A project to lighten the load of fediverse instances via shared infrastructure.
* **[NilLoader](https://git.sleeping.town/Nil/NilLoader)** - The universally-compatible ultra-light mod loader.
* **[Ears](https://git.sleeping.town/exa.mods/Ears)** - Faithful fancy fashion features for fuzzy folk.
* **[Partyflow](https://git.sleeping.town/exa/Partyflow)** - A self-hosted media transcoding service and release manager styled around Bandcamp.
* **[unbted](https://git.sleeping.town/exa/unbted)** - µ NBT Editor - an advanced interactive command-line NBT editor

Noteworthy stuff we helped with:
* **[the Fractureiser malware investigation](https://github.com/trigram-mrp/fractureiser)**
* **[Voldeloom](https://codeberg.org/CrackedPolishedBlackstoneBricksMC/voldeloom)** - A modern Gradle plugin for old versions of Forge (quat has since entirely rewritten it)
